🧮 FRACCIONES

Una fracción representa partes de un todo. Ejemplo: 1/2 significa una parte de dos.

🔹 Suma de fracciones

Paso 1: Multiplica cruzado
Paso 2: Suma los resultados
Paso 3: Multiplica denominadores
Ejemplo:
1/2 + 1/3
1×3 = 3 y 1×2 = 2
3 + 2 = 5
2×3 = 6
Resultado: 5/6

🔹 Resta

3/4 - 1/2
3×2 = 6, 1×4 = 4
6 - 4 = 2
4×2 = 8
Resultado: 2/8 = 1/4

🔹 Multiplicación

3/4 × 2/3
3×2 = 6
4×3 = 12
Resultado: 6/12 = 1/2

🔹 División

3/4 ÷ 2/3
Se invierte la segunda fracción:
3/4 × 3/2 = 9/8

🔹 Simplificación

Divide numerador y denominador por el mismo número
6/12 = 1/2

📈 ECUACIONES DE SEGUNDO GRADO

Son ecuaciones que tienen la forma:

ax² + bx + c = 0

🔹 Paso a paso

Paso 1: Identificar a, b y c
Paso 2: Calcular el discriminante D = b² - 4ac
Paso 3: Aplicar fórmula general

🔹 Ejemplo completo

x² - 5x + 6 = 0

a = 1, b = -5, c = 6

D = (-5)² - 4(1)(6)
D = 25 - 24 = 1

x = (-b ± √D) / 2a
x = (5 ± 1) / 2

x₁ = (5 + 1)/2 = 3
x₂ = (5 - 1)/2 = 2

Resultado: x = 2 y x = 3

🔹 Casos del discriminante

D > 0 → dos soluciones
D = 0 → una solución
D < 0 → no hay solución real

⚡ POTENCIAS

aᵐ · aⁿ = aᵐ⁺ⁿ
aᵐ / aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
Ejemplo:
2² × 2³ = 2⁵ = 32

📐 PRODUCTOS NOTABLES

(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²
(a + b)(a - b) = a² - b²
Ejemplo:
(x + 2)² = x² + 4x + 4
